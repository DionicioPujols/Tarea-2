## 🎯 Objetivo de la Práctica
Desarrollar una aplicación de consola en Java que permita registrar vehículos, aplicando los fundamentos de la programación orientada a objetos. La finalidad es poner en práctica:
- Clases y objetos
- Métodos y constructores

- Encapsulamiento
- Uso de Arrays o ArrayList
- Manejo básico de cadenas de texto

## 📝 Descripción
Una agencia de vehículos necesita un sistema sencillo para registrar y consultar vehículos disponibles. Este sistema permite almacenar la información básica de diferentes vehículos y mostrarla a través de un menú interactivo, facilitando la gestión y búsqueda de los mismos.

## ⚙️ Funcionalidades y Opciones del Menú
El sistema cuenta con un menú interactivo que permite al usuario realizar las siguientes acciones:
1. **Registrar vehículo:** Permite ingresar la placa, marca, modelo, año, color y precio.
2. **Mostrar vehículos:** Despliega en pantalla todos los vehículos que han sido registrados.
3. **Buscar vehículo por placa:** Filtra y muestra la información de un vehículo específico utilizando su placa.
4. **Mostrar vehículos por marca:** Muestra una lista de todos los vehículos que pertenecen a una marca específica.
5. **Salir:** Finaliza la ejecución del sistema.

## 🛠️ Requisitos Técnicos Aplicados
- Implementación de la clase `vehiculo`.
- Uso de constructores y métodos (separados en la clase `Metodos`).
- Aplicación de encapsulamiento.
- Almacenamiento en memoria mediante `Arrays` o `ArrayList`.
- Menú interactivo con validaciones básicas.
- Lógica de programación distribuida en clases, evitando concentrar todo en el `main`.
